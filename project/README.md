# Landing Page

A modern, responsive landing page with smooth animations and interactive features.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Smooth Scrolling**: Navigation links smoothly scroll to sections
- **Animations**: Fade-in animations for better user experience
- **Contact Form**: Interactive form with validation
- **Modern UI**: Clean, professional design with gradient hero section

## Structure

- `index.html` - Main HTML structure
- `styles.css` - All styling and responsive design
- `script.js` - Interactive features and animations

## Sections

1. **Navigation Bar**: Sticky navbar with logo and navigation links
2. **Hero Section**: Eye-catching gradient background with CTA buttons
3. **Features**: Three-column grid showcasing key features
4. **About**: Information section about the company/product
5. **Contact**: Contact form for user inquiries
6. **Footer**: Copyright information

## Usage

Simply open `index.html` in a web browser to view the landing page.

## Customization

- Update the brand name in the navbar
- Modify colors in `styles.css` (primary color: `#4f46e5`)
- Add or remove features in the features section
- Update text content to match your product/service
